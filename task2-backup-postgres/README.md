# PostgreSQL Backup Script

Bash-скрипт для создания локального ежедневного и месячного backup PostgreSQL с автоматической ротацией и запуском по cron.

## Что делает скрипт

Скрипт:

* создаёт backup PostgreSQL с помощью утилиты `pg_dump`
* сохраняет ежедневные backup-файлы в `daily/` и оставляет 7 последних ежедневных backup-файлов
* backup, созданный в последнее воскресенье месяца, дополнительно сохраняется в `monthly/` и не подлежить ротации
* записывает результат работы в лог
* позволяет установить ежедневный запуск через cron

## Требования
* PostgreSQL
* PostgreSQL client (`pg_dump`)
* cron


## Переменные окружения

Параметры подключения и пути задаются через переменные окружения из файла `.backup.env`:

```bash
export PGHOST=your_host
export PGDATABASE=your_database
export PGUSER=your_user
export BACKUP_DIR=your_backup_directory
export LOG_DIR=your_log_directory
export PGPASSWORD=your_password
```


## Ручной запуск

Для создания backup выполните:

```bash
./backup.sh
```

После выполнения ежедневный backup будет находиться в:

```text
$BACKUP_DIR/daily/
```


## Справка

```bash
./backup.sh --help
```

## Установка cron

Для установки ежедневного запуска:

```bash
./backup.sh --install-cron
```

Скрипт устанавливает запуск каждый день в 02:00:

```text
0 2 * * * /opt/postgres-backup/backup.sh
```

Проверить установленное задание:

```bash
crontab -l
```

## Ротация backup-файлов

### Daily

В каталоге `daily/` хранятся последние 7 backup-файлов.

При создании нового backup более старые файлы удаляются.

### Monthly

Если текущий день — последнее воскресенье месяца, созданный backup дополнительно копируется в:

```text
$BACKUP_DIR/monthly/
```

Таким образом, сохраняется один monthly backup за каждый месяц.

## Логи

Результат работы скрипта записывается в:

```text
$LOG_DIR/
```

Для каждого дня создаётся отдельный лог:

```text
backup_YYYY-MM-DD.log
```


## Обработка ошибок

Если `pg_dump` завершается с ошибкой:

* выводится сообщение об ошибке
* незавершённый backup-файл удаляется
* скрипт завершается с ненулевым кодом


## Что можно улучшить

При наличии дополнительного времени можно:

* использовать `.pgpass` вместо `PGPASSWORD`
* добавить проверку целостности созданного backup
* добавить проверку дискового пространсва для создания нового backup
